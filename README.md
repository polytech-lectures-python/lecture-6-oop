# ООП (объектно-ориентированное программирование)

## Структура

1. `1_basic` - основы ООП
2. `2_properties` - свойства и дескрипторы
3. `3_closures` - замыкания
4. `4_class_and_static_methods` - методы класса и статические методы
5. `5_abstract_base_classes` - абстрактные классы и метаклассы

## Как запустить

Для управления зависимостями используется Poetry:

```bash
poetry install --no-root
peotry run <script-name.py>
```
